# 默认英文与中文路径设计

## 意图

让 Interview Compass 默认以英文访问，中文页面统一使用 `/zh/` 前缀，并让站点文案更直接、自然，减少无助于用户判断的防御性说明和模板化表达。

## 目标与边界

- 英文首页和全部英文页面使用根路径；中文页面使用 `/zh/`。
- 导航、面包屑、搜索、分页、语言切换、规范链接和静态数据链接都与新路径一致。
- 原有 `/en/` 英文链接保留兼容跳转。原中文根路径与新的英文根路径完全重合，切换后根路径提供英文，无法同时将相同 URL 用作中文跳转。
- 调整全站用户可见的界面与说明文案；保留必要的事实边界、安全提示和内容准确性。
- 完善 SEO/GEO 基础：自引用 canonical、双语 hreflang、语言站点地图、可抓取页面元数据与适合实际页面内容的结构化数据；不把非标准 AI 文件宣称为排名信号。
- 核实 robots 与 GitHub Pages 子路径部署边界，避免生成指向错误域名根目录的声明。
- 不改题库知识内容、评估框架、数据结构或视觉设计。

## 方案

1. **迁移页面树并统一路径生成（采用）**：把英文页面放到根路径、中文页面放到 `/zh`，更新路径生成器并为旧路径保留跳转。匹配部署产物和用户期望的 URL，静态页面也能直接部署。
2. **保留文件树并增加 URL 重写**：减少文件迁移，但依赖部署平台重写规则，GitHub Pages 无法原生保证所有旧路径及分页规则。

## 约束与判断

- 站点使用 Astro 静态构建，部署在带 `/interview-compass` base 的 GitHub Pages。
- GitHub Pages 静态输出不能发送 HTTP 301；旧 `/en/` URL 使用 `noindex` 的客户端跳转页兼容访问，规范链接和站点地图只使用新 URL。
- 内容、页面组件和 UI 已有中英文支持；路径约定集中在 `src/lib/routes.ts`。
- Google Search 官方指南指出 AI 搜索仍依赖基础 SEO，`llms.txt` 不影响 Google 搜索展现；若增加此文件，只作为其他系统的可选站点索引。
- 以现有页面内容为基础，不做逐句直译式重写；删掉重复的免责声明式铺垫，具体说明仍保留。
- 设计与实现由本任务直接推进；验证使用 Astro 检查和静态构建，不增加或运行测试。
