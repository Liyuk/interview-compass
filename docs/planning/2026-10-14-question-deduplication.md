# 面试题去重记录

日期：2026-10-14。范围：所有已发布的简体中文题目及其英文配对。去重先于题卡与评分结构改造。

## 方法

先将 100 组批量生成题各自收敛为一张题卡：保留一个主问题，把同组不同情境的追问并入 `followUps`。随后按稳定的题目 ID 顺序，串行比较每一对中文题面。脚本使用中文词语与字符二元组的 TF-IDF 加权余弦相似度生成候选；相似度只用于筛选，不自动删除。对候选逐组检查题目要解决的问题、责任层级、决策阶段和需要的证据，再决定合并或保留。

## 合并结果

首轮跨题审核后曾保留 584 道中英配对题。其后再次按稳定 ID 顺序审查相似度候选，发现并合并 15 张重复题卡，分别归入 12 道保留题；当前题库为 **569 道中英配对题**。连同首轮跨题合并，累计合并 39 张跨题卡。合并保留了独有的约束、观察信号、追问和来源，并将题目关系与来源台账中的旧 ID 映射到保留题。

跨题组合并主要包括：

- 并发过期映射与重试器实现题、增量解析器与大型日志流解析、区间合并、内存增长诊断、虚拟内存缺页诊断及并行测试中的不稳定失败。
- 基础设施配置漂移、CI 不可信变更隔离、大文件上传与安全扫描、分布式租户限流、RAG 更新与删除传播、AI 诊断观测与敏感信息保护。
- 客户定制产品化、渠道扩量后的边际效率、活动增量归因、时间穿越特征、可复算特征契约、依赖负责人和排期。
- 面试官对候选人主张的证据追问、授权后增加复核、个人失误复盘与后续行为变化。

## 本轮追加去重

日期：2026-10-14。先将相似度阈值设为 0.15，串行比较 584 道题的全部 170,236 对题面，再逐条审阅 73 个候选。合并的重复主题包括：Agent 工具超时和副作用重试、数据删除跨系统传播、特征时间穿越、共享凭证轮换、多优惠叠加、项目结果因果归属、晋升材料中的个人与团队贡献、结果未达标后的责任复盘、行业参照层级、分布式事件时序、移动端进程回收后的状态恢复，以及有界可取消的重试封装。

复审后再次运行相似度审计：569 道题共比较 161,596 对；0.18 阈值产生 25 个候选，0.15 阈值产生 57 个候选。剩余候选逐项人工检查后均保留，因为它们的责任层级、故障条件、业务对象、决策阶段或所需证据不同。例如，搜索系统设计与索引迁移、告警降噪与交接漏接、管理者冲突与管理者协作机制、成本模型与产品投资回报，分别考察不同问题。

同时清理了 85 道批量题中重复出现的五条通用追问和域内重复信号：追问信息交由统一上下文框架补足，题目意图与观察信号则按题面和能力域重写。去重后，所有保留题的评分锚点都引用本题信号。

## 保留为独立题目的边界

首轮串行扫描过 584 道题的 **170,236 个题目对**，在 0.18 阈值下得到 28 组候选；这些判断已由本轮更宽松阈值复核覆盖。当前 569 道题的候选数与保留理由见“本轮追加去重”。候选相似度只用于发现可能重复，不能代表内容质量或语义等价。

相似度阈值不是内容质量或语义等价的证明。今后有新题加入时，应重新运行 `SIMILARITY_THRESHOLD=0.18 node scripts/audit-question-similarity.mjs`，再由维护者逐条复核候选。来源台账中被合并题目 ID 均映射到保留题目；站点链接和中英文题目配对按新 ID 校验。
