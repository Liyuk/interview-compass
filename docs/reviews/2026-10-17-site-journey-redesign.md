# 全站交互与用户动线改造验收
> **Historical record:** This document records a plan or review from its date; its framework and implementation statements are not current. See the [current architecture](../architecture/current-state.md).


## 用户目标与实现

以工程师找题和连续阅读为主线，修复跨页面主导航丢失，并将准备目标状态从全宽栏移到页头右上角。设计和计划见 `docs/superpowers/specs/2026-10-17-site-journey-redesign-design.md`、`docs/superpowers/plans/2026-10-17-site-journey-redesign.md`。

| 要求 | 实现与证据 |
| --- | --- |
| 全站主导航一致 | SiteMasthead 始终输出六入口；site-navigation.ts 统一所属板块；静态全路由扫描与中英代表路由浏览测试 |
| 新用户直接访问 | 取消自动目标弹窗；首次访问浏览器用例 |
| 目标状态不推动正文 | 固定尺寸右上角入口、绝对定位浮层；390/1440px 展开前后正文 y 相等；Escape、外部点击与焦点离开关闭 |
| 目标索引失败可恢复 | 错误与重试入口、清除拒绝的请求缓存；503 后恢复成功的浏览器用例 |
| 找题优先 | 题库/搜索/题单索引使用宽发现布局，无全站知识树；768/1024px 正文宽度断言 |
| 阅读优先 | 题目/题单/路径/方法为阅读布局；空目录不占列，短页面不显示空目录 |
| 局部导航 | 分类、阶段、目标路径仅展示所属板块；独立分类不伪造为同一父子树 |
| 连续读题 | 顶部和页尾返回共享来源；安全接受目标参数、分页及阶段来源；筛选第2页及滚动/展开状态恢复用例 |
| 首页入口层级 | 保留按目标开始、直接搜索、分类和精选题单，将重复的六任务区合入目标路径页 |
| 手册一致 | 自定义 Starlight PageFrame 接入自然高度共享页头；保留正文、本地化和唯一 TOC；消除旧固定高度与移动菜单补偿 |
| 首屏稳定 | 侧栏与本页目录在绘制前处理折叠；独立脚本作用域避免变量冲突；延迟脚本的手机题目与手册布局偏移断言 <0.05 |
| 全站路径有效 | 静态扫描发现并修复英文404中文切换指向不存在路径的问题；中文切换落到实际404.html |
| 原有数据与筛选 | 内容/阶段覆盖校验、Pagefind搜索与目标偏好端到端测试；数据记录与来源未更改 |

## 已知限制

- 静态站点的全文搜索仍需要 JavaScript；无脚本时可浏览静态题库与导航。
- 目标偏好仅存在当前浏览器；存储受限时仅本页生效，界面显示提示。
- 不提供学习进度、标准答案或自动评分；不将读题记录冒充学习成果。
