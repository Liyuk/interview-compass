title: How should priorities change when a metric improves while some users are harmed?
question: >-
  A redesign improves average conversion but increases task failure for a constrained user group; expanding
  the sample requires more research time. How would you prioritize the risk and decide whether to pause
  rollout?
intent: Assess value judgment and guardrail use when aggregate benefit conflicts with segment harm.
signals:
  - Compares aggregate benefit with the severity of task failure for the affected group.
  - Considers uncertainty, reversibility, and whether affected users have an alternative path.
  - Defines thresholds for pausing, adding research, or continuing a limited experiment.
  - Separates average efficiency, completion rate, and severe task failure.
  - Identifies affected users, contexts, alternatives, and severity.
  - Sets guardrails that aggregate gains cannot offset and assigns remediation ownership.
