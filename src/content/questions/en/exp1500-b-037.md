  An event producer wants to change a field from a string to a structured object, but some consumers deploy
  slowly and others drop unknown fields when writing records back. How would you stage dual writes, version
  negotiation, migration, and retirement of the old format?

  - Chooses a backward-compatible transition that avoids ambiguous meanings.
  - Monitors old and new write rates, parse failures, and round-trip data loss.
  - >-

    compatibility code.
