title: How would you safely sync edits made across offline devices?
question: >-
  Users can edit a profile on a phone while offline and may also edit it on the web. The device must sync when
  connectivity returns without silently overwriting valuable changes. How would you design versioning,
  conflict detection, merging, and user confirmation?
intent: Assess consistency boundaries, conflict semantics, and recovery experience in multi-device offline sync.
signals:
  - Defines object versions, edit ordering, and the basis for conflict detection.
  - Distinguishes fields safe to merge automatically from conflicts that must preserve both versions.
  - Covers duplicate delivery, device-clock skew, undo, and sync-failure recovery.
  - Uses versions or an equivalent mechanism to detect concurrent edits
  - Avoids silently overwriting the other update
  - Chooses merging, user choice, or rejection according to field risk
