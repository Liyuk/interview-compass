title: What if feature usage rises but the target outcome does not improve?
question: A new feature is used far more than expected, but the share of target users completing their core task is unchanged and support inquiries increase. How would you decide whether the feature creates user value and whether to continue, revise, or retire it?
intent: Assess product-value judgment based on user-task outcomes rather than feature adoption.
signals:
  - Distinguishes clicks, use, task completion, and user outcomes as different evidence.
  - Checks user segments, motivations, and unresolved task barriers.
  - Compares the cost of fixing, repositioning, or retiring the feature and defines the next validation criteria.
