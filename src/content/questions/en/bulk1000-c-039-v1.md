title: High activity does not equal high value
question: >-
  A feature is used often but has not improved retention or payment. How would you determine whether it
  creates core value, reflects habit, or rewards the wrong behavior?
intent: >-
  Assess how you handle “High activity does not equal high value”: clarify goals and constraints, make an
  evidence-based judgment, and explain how you would verify outcomes and trade-offs.
signals:
  - >-
    Verify use, task completion, retention, and payment by user and motivation rather than treating
    clicks as value.
  - >-
    Compare core tasks, friction, habit, and distorted incentives, seeking evidence that distinguishes
    causes.
  - >-
    Assess user impact, maintenance, and opportunity cost of retaining, fixing, repositioning, or
    retiring.
  - Set next validation and review conditions, recognizing value beyond direct payment gains.
