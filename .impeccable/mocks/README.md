# Historical design explorations

The mockups, prompt files, JSON sidecars, and reroll folders in this directory are preserved design explorations from earlier site directions. Their framework names, proposed navigation labels, and sample layouts describe those experiments, not the current implementation. Use [the current architecture](../../docs/architecture/current-state.md) for the running shell, routes, content sources, and module ownership.

`references/user-supplied-reference.png` is retained as supplied visual reference material. Generated mock images and prompt metadata are not production assets or implementation guidance.
